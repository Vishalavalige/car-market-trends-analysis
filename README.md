# Car Market Trends Analysis with CarDekho Data

A data analytics mini project analyzing 301 real used-car listings from CarDekho to uncover what actually drives resale price in the Indian second-hand car market.

**VOIS x Edunet Foundation Internship — Data Analytics Mini Project**

## 📊 Overview

Used car buyers and sellers often lack a reliable, data-driven way to judge fair resale value. This project analyzes real listing data to find patterns across fuel type, transmission, mileage, ownership history, and vehicle age.

## 🔑 Key Findings

- **Diesel & automatic cars sell for more** — Diesel cars average ~₹10.3 lakh vs ~₹3.3 lakh for petrol; automatic transmission cars average ~₹9.4 lakh vs ~₹3.9 lakh for manual.
- **Present price is the strongest predictor** — Selling price closely tracks the original showroom price (r ≈ 0.88).
- **Newer cars fetch higher prices** — Cars manufactured post-2015 show a clear upward trend in resale value, reflecting lower mileage and less depreciation.

## 🛠️ Tools Used

- Python (Pandas, NumPy) — data cleaning & analysis
- Matplotlib & Seaborn — data visualization
- Google Colab / Jupyter Notebook — exploratory analysis
- CSV Dataset — CarDekho used car listings (301 records, 9 features)
